# Simuladores de IA y computación en la nube

Los programas de los simuladores de [rubenjarne.dev/ia-nube](https://rubenjarne.dev/ia-nube), uno por
cada caso que se puede montar en cada simulador. Son Python sin librerías: abre el `.py` del caso y pulsa el triángulo verde.

Lo normal es no navegar por aquí: el botón **«Ábrelo en PyCharm»** del simulador abre
directamente el programa del caso que tienes montado. Si el repositorio cambia: **Git → Pull**.

Este repositorio lo genera la web a partir de sus simuladores: no se edita a mano.

- `frontera-de-decision/`: 40 casos
- `k-means/`: 4 casos
